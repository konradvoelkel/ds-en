the scikit-learn cross-validation plots), and plots generated by the notebooks.

## Redrawn figures

`make_figures.py` regenerates the two matplotlib figures below; run it with
`uv run python images/make_figures.py`. The script is the source, the PNG is the output.

* `stochastics-overview.svg` – hand-written SVG, replaces `stochastik-statistik-wtheorie.png`.
  Layout follows the original exactly; colours are the HHU house colours from `BRANDING.md`
  (lines `#006AB3`). White background and dark text, like every other figure in the book.
  Edit the SVG directly – it is the source.
* `simpson-paradox.png` – regenerated by `make_figures.py`, seeded, same geometry as the
  original: both groups rising, the pooled trend falling.
* `ds-process-1.svg`, `ds-process-2.svg`, `ds-process-3.svg` – written by `make_figures.py`
  as SVG, since they are line drawings rather than plots. The German original's globe is a
  detailed drawing of the Americas with no source; this one is a plain graticule globe,
  which says the same thing and can be edited.
* `chi-squared-distributions.png`, `student-t-distributions.png` – regenerated by
  `make_figures.py` from scipy densities; only the suptitle and the legend were German.
* `colour-vision-simulation.png` – regenerated by `make_figures.py`. Okabe-Ito palette under
  the Vienot-Brettel-Mollon (1999) dichromat simulation the chapter's caption names. The
  LMS matrix and the tritanopia half-plane were both checked against the German figure's
  own pixels; see the comments in the script, which record the two ways this goes wrong.
